# 문제풀이

Java, CS, Spring 세 과목, 과목마다 초급·중급·고급 각 100문제(총 900문제)를 랜덤으로 뽑거나 직접 골라서 푸는 프로그램입니다.
점수와 정답은 **풀이를 종료한 뒤에만** 공개됩니다.

## 폴더 구성

```
java-quiz/
├── index.html              화면
├── style.css               디자인
├── app.js                  동작 (CSV 읽기, 출제, 채점)
└── questions/              문제 pool (엑셀로 열 수 있는 CSV)
    ├── beginner.csv         Java 초급 100문제
    ├── intermediate.csv     Java 중급 100문제
    ├── advanced.csv         Java 고급 100문제
    ├── cs_beginner.csv      CS 초급 100문제
    ├── cs_intermediate.csv  CS 중급 100문제
    ├── cs_advanced.csv      CS 고급 100문제
    ├── spring_beginner.csv     Spring 초급(하) 100문제
    ├── spring_intermediate.csv Spring 중급 100문제
    └── spring_advanced.csv     Spring 고급(상) 100문제
```

## 실행 방법

**방법 1. 로컬 서버로 열기 (추천)**

```bash
cd ~/Desktop/java-quiz
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 열면 questions 폴더를 자동으로 읽습니다.

**방법 2. index.html 더블클릭**

브라우저 보안 때문에 CSV를 자동으로 못 읽을 수 있어요. 그때는 화면의 **CSV 파일 선택** 버튼으로
`questions` 폴더의 CSV들을 한꺼번에 고르거나 끌어다 놓으면 됩니다.

## 사용법

1. 과목(Java / CS / Spring)을 고릅니다.
2. 난이도(초급/중급/고급)를 고릅니다.
3. 출제 방식을 고릅니다.
   - **랜덤 출제**: 문제 수, 분류, 유형(객관식/주관식)을 정하면 무작위로 뽑습니다.
   - **직접 선택**: 목록에서 분류·유형·검색으로 찾아 원하는 문제를 체크합니다.
4. 풀이 중에는 정답 여부가 보이지 않습니다. 문제 번호 버튼으로 자유롭게 오가며 답을 고칠 수 있어요.
5. **풀이 종료**를 누르면 점수, 분류별 정답률, 문제별 정답과 해설이 나옵니다.
6. 결과 화면에서 **틀린 문제만 다시 풀기**로 오답만 복습할 수 있어요.

키보드: 객관식은 `1`~`4`로 보기 선택, `←` `→`로 문제 이동, 주관식은 `Ctrl+Enter`(Mac은 `⌘+Enter`)로 다음 문제.

## 문제 추가·수정하기

CSV 파일의 열 구성은 다음과 같습니다. 새 문제는 아무 파일에나 한 줄 추가하면 되고, 어느 과목·난이도에 들어갈지는 **과목**, **난이도** 열로 정해집니다.

| 열 | 설명 | 예 |
|---|---|---|
| 번호 | 겹치지 않는 고유 번호 | CB101 |
| 과목 | 자유롭게 (같은 이름끼리 묶임, 비우면 Java) | CS |
| 난이도 | 초급 / 중급 / 고급 | 초급 |
| 분류 | 자유롭게 (같은 이름끼리 묶여 필터에 나옴) | 네트워크 |
| 유형 | 객관식 / 주관식 | 주관식 |
| 문제 | 문제 문장 | HTTP의 기본 포트 번호는? |
| 코드 | 보여 줄 코드나 표 (여러 줄 가능, 없으면 비움) | |
| 보기1~보기4 | 객관식 보기 (주관식은 비움) | |
| 정답 | 객관식은 보기 번호 1~4, 주관식은 답. 여러 답을 인정하려면 `\|`로 구분 | `64\|0x64` |
| 해설 | 결과 화면에 보여 줄 설명 | |

- 새 과목을 만들려면 과목 열에 새 이름(예: 영어)을 쓰면 첫 화면에 과목이 자동으로 생깁니다.
- 새 CSV 파일을 만들었다면 `app.js` 맨 위의 `POOL_FILES` 목록에 파일 경로를 추가하세요.
- 객관식 보기 순서는 풀 때마다 섞여서 나옵니다. CSV의 정답 번호는 **CSV에 적힌 보기 순서** 기준으로 쓰면 됩니다.
- 주관식 채점은 대소문자, 공백, 쉼표, 괄호, 따옴표 차이를 무시합니다. (`[1, 2, 3]`과 `1 2 3`은 같은 답으로 처리)

### 엑셀로 편집할 때 주의

엑셀은 숫자처럼 보이는 값을 자동으로 바꿔서 저장합니다. 예를 들어 정답 `01234`는 `1234`로, `3.0`은 `3`으로,
`0010`은 `10`으로 바뀌어 채점이 틀어질 수 있어요.

- 보기만 할 때는 엑셀로 열어도 괜찮습니다.
- 수정해서 저장할 때는 VS Code 같은 텍스트 편집기를 쓰거나, 엑셀의 **데이터 → 텍스트/CSV 가져오기**에서 정답 열을 **텍스트** 형식으로 지정해 불러온 뒤 **CSV UTF-8** 형식으로 저장하세요.
